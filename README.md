# مشروع دمج وتنظيف ومعالجة البيانات وتجهيزها لتعلم الآلة

## 📌 نبذة عن المشروع

يهدف هذا المشروع إلى بناء نظام لمعالجة البيانات باستخدام لغة Python، حيث يتم جمع البيانات من ثلاثة مصادر مختلفة:

1. ملفات CSV
2. ملفات JSON
3. قاعدة بيانات Database

بعد جمع البيانات، يتم تنفيذ مجموعة من عمليات معالجة البيانات، مثل:

- قراءة البيانات.
- التحقق من صحة البيانات.
- اكتشاف البيانات الناقصة.
- معالجة القيم المفقودة.
- اكتشاف وإزالة البيانات المكررة.
- تصحيح أنواع البيانات.
- توحيد أسماء الأعمدة.
- توحيد تنسيق البيانات.
- دمج البيانات القادمة من المصادر المختلفة.
- معالجة البيانات وتجهيزها.
- تحويل البيانات إلى Dataset جاهز للاستخدام في نماذج Machine Learning.

---

# 🎯 أهداف المشروع

يهدف المشروع إلى:

- تعلم التعامل مع مصادر بيانات مختلفة.
- استخدام Python في بناء Data Pipeline.
- استخدام Pandas لمعالجة البيانات.
- تطبيق عمليات Data Cleaning.
- دمج البيانات القادمة من أكثر من مصدر.
- تطبيق Data Preprocessing.
- إنتاج Dataset موحد ونظيف.
- تجهيز البيانات لتكون مناسبة لتدريب نماذج Machine Learning.
- تطبيق Git وGitHub في العمل الجماعي.
- استخدام Branches وCommits وPull Requests وCode Review.
